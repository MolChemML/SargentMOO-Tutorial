# Sargent Centre Optimisation Accelerator

**7–10 September 2026**  
**Day 3: Principles of Multi-Objective Optimisation**

A hands-on bi-objective optimisation tutorial exploring weighted sum, epsilon-constraint, modified normal boundary intersection (NBI), and NSGA-II methods.

## Getting started

[**Open the student notebook in Google Colab**](https://colab.research.google.com/github/MolChemML/SargentMOO-Tutorial/blob/main/Students_bi_objective_optimization_tutorial_colab.ipynb)

1. Open the link above and sign in to your Google account.
2. Select **Copy to Drive** to save your own working copy.
3. Run the setup cells in order to install the required packages.
4. Complete each **To Do** exercise before running its method.

The notebook automatically downloads the precomputed reference fronts. No manual data upload or Google Drive mounting is required. The original computation fallback is preserved: if the cache is unavailable or does not match the current objective scaling, it is rebuilt. Rebuilding can take a long time.

## Files

- `Students_bi_objective_optimization_tutorial_colab.ipynb` — student notebook and exercises.
- `pareto_reference_fronts_normalised.npz` — precomputed normalised Pareto reference fronts.
